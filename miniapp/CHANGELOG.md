# SelfAgent 小程序更新日志

版本号与体验版上传号对应；日期为北京时间。

## 1.0.24 · 2026-11-24

**AI 找动作 / 拍照识别改为「解析 → 全库召回 → 重排 → 反问」**
- 新增 `libs/find.js` 检索层：部位/器械别名表（龙门架=绳索、夹胸=飞鸟、上胸=上斜…）、伤病降权、全库 5632 条打分召回（最多 90 条）。
- AI 拆成两次调用：第一次只解析成 `{部位, 器械, 动作模式, 关键词, 伤病/场地限制, 缺失条件}`，不检索；第二次对 90 条候选重排，允许返回 `notFound`（库里没有）与 `clarify`（反问）。
- 候选池不再被本地关键词筛死的 20 条限制；同一查询有 90 条召回兜底。
- 低置信（选出 <4 个）时才弹澄清按钮（如「健身房器械 / 只有哑铃 / 自重在家」），点击即补条件重跑。
- 字号/名称按语义匹配：AI 不再因为「龙门架夹胸」与「绳索飞鸟」字面不同而判「没有」，name alias 也补了 id 补零容错。
- 拍照识别改用同一套：视觉模型输出 `{scene, equipment, part, actions, keywords}`，再走召回 + 重排；画面条件（器械/部位）会传给重排，拍到龙门架不会再塞弹力带/哑铃版本。
- 实测：`我想练背但是腰不好` → 7 个坐姿/卧姿、护腰动作并带理由；`龙门架夹胸` → 8 个绳索飞鸟/交叉；`想练臀 家里只有弹力带` → 弹力带臀桥/髋顶髋等；龙门架照片 → 绳索高位下拉/坐姿划船直配 + 8 个绳索动作。截图 `t9/y1-aifind-back.png`、`y2-aifind-cable.png`、`y4-scan.png`。

## 1.0.23 · 2026-11-24

**收工页「加练」+ 整场用时修正**
- 收工页新增「＋ 加练，再挑个动作」：跳动作库挑选，回来自动追加到本次训练末尾并直接进入该动作第 1 组计时，可继续做完再收工。
- 「用时」原来只累加有氧时长，力量训练恒为 `0 秒`；改为按整场真实时钟计算（含组间休息），并持久化 `startAt`，退出重进接着算（12 小时内）。

## 1.0.22 · 2026-11-24

**拍照识别：修多模态请求、补通道诊断**
- 根因：`libs/ai` 的 `maskMessages` 把 `content` 数组当字符串处理，图片块（`image_url`）被拍平丢失；且手机端没读到自定义 API 配置时会回落到云函数 `aiProxy`，而云端超时仍是 3 秒 → `-504003 FUNCTIONS_TIME_LIMIT_EXCEEDED`。
- 修复：多模态只对 `text` 块做匿名化，`image_url` 原样保留；预览与字符统计不再把 base64 拼进设置。
- 拍照页顶部显示当前通道（`直连 apihub.agnes-ai.com/v1 · agnes-3.0-flash` / `云端 aiProxy（未配自定义 API）`），失败时按类型给可执行提示（域名未白名单 / 云函数 3 秒超时 / 401 Key 被拒）。
- `pages/apiconfig` 新增「识图测试」：发送 1×1 红图，模型答「红色」即图片块与视觉模型都通。
- 实测：真实健身房龙门架照片（320px/19KB）经直连模型识别出 6 个动作，其中 3 个命中动作库；1×1 红图返回「红色」。

## 1.0.21 · 2026-11-24

**本组计时：暂停 / 继续、重置**
- 计时区下方新增两个 chip：「暂停计时 / 继续计时」「重置本组」，仅在做组时显示。
- 暂停：`_pauseAt` 记下暂停时刻，`elapsedMs()` 扣掉这段，`tick` 跳过刷新，`mmss` 冻结；圆环下文案变「已暂停」。
- 继续：把暂停时长累加进 `_pauseAcc`，立刻 `tick` 补一帧。
- 重置：`_workStart=Date.now()`、`_pauseAcc/_pauseAt=0`，`mmss 0:00` 从零开始，暂停态一并解除。
- 暂停态也随现场落盘：`persistFocus` 存 `pauseAcc/pauseAt/timerPaused`，重进页面仍是暂停且秒数冻结。完成本组时按扣除暂停后的净时长入账。

## 1.0.20 · 2026-11-24

**修复：息屏/切后台后本组计时停在离开前的秒数**
- 根因两层：① 小程序退到后台后 `setInterval` 被挂起，画面不再刷新；② 1.0.19 里 `onHide` 记 `_hideAt`、`onShow` 又把这段时长从 `_workStart` 平移掉，等于主动把后台时间剔除了。
- 改为纯系统时间差计时（`mmss((Date.now()-_workStart)/1000)`），`onHide` 只落盘、`onShow` 立即 `tick()` 补帧，后台时长照常计入。
- 进程被杀/页面销毁也能接上：`persistFocus` 额外存 `workStart`，`restoreFocus` 读回（6 小时内有效），`prepare` 用它当起始时刻，重开直接显示累计用时。
- 实测：本组 5s → `onHide` 6s → `onShow` 显示 `13″` 并以此入账；页面销毁重开后 `mmss 0:09`、完成后该组 `9″`。

## 1.0.19 · 2026-11-24

**专注模式：每组自动计时**
- 力量动作进入该组即开始计时（`prepare` 直接进 `work`，不再有「准备态」），圆环中间显示 `m:ss` 本组用时。
- 完成本组一律写入实际秒数（`completeGroup` 取 `elapsedSec()`，至少 1 秒）；组行右侧即时显示该组时长（如 `45″`）。
- 切后台/锁屏不计入：`onHide` 记录隐藏时刻，`onShow` 把这段从 `_workStart` 平移掉。
- 组间休息中点组行 = 结束休息并开始下一组计时（避免没做过的一组被记成 0 秒）。
- 点非当前组只记该组完成与时长，不打断手上正在计时的那一组。
- 「重做」清零该组 `sec` 并从会话时长扣回该组原用时；收工页「用时」按真实累计时长显示。
- 保存训练时 `rpe` 不再被写成 0（原 `saveStrength` 硬编码 `rpe: 0`）。
- 设置页移除「组内计时」开关（每组恒计时），改为一句话说明。

**日志每组时长**
- 记录页展开某动作后，每组右侧显示该组时长（`gsec`，青绿 20rpx）；动作行标题追加本动作总时长（`自重 3×10 · 1′35″`）。
- 数据链路：`saveStrength` → `records[].groups[].sec` → `engine.syncTrainLog` 重建当天 `logs[].meta.items` → 记录页 `buildTimeline` 读取，无需额外落库。

## 1.0.18 · 2026-11-24

**专注页：运动项增删查改**
- 动作清单每行改为两行：首行序号/名称/有氧标记/状态，次行右对齐「详情 · 改 · 删」三个操作。
- 详情：任意项打开 `ex-sheet`（动图 + 部位/器械/要领），无 `exId` 时按名称匹配兜底。
- 改：复用 `train-editor` 弹层，改动写回该动作各组（次数/重量/完成态/热身/标签/RPE），有氧计组型改走 `saveCardio`。
- 删：`wx.showModal` 二次确认后按类型调 `deleteStrength` / `deleteCardio`，移除该项并重排序号、重算组数；删空自动进收工页。
- 加：清单底部「＋ 中途加个动作」，收工页顶部新增「本次 N 个动作 · X/Y 组 管理 ⌄」入口。

**重做某一组**
- 组行已完成的组出现「重做」chip：该组 `done/sec/rpe` 归零、总会话时长扣回该组原用时，并自动定位到该组。
- 收工页可点清单任意一项回到该动作，再在组行重做指定组（`jumpTo` 在 finish 态允许回跳当前项）。

**组间休息圆环修复**
- 根因：`onReady` 只在准备态量到 canvas（520×336）却按正方形算半径，进入休息态后位图被竖向拉伸 → 椭圆、弧线冲出表盘。
- 改为 `initCanvas` 记录宽高两维、位图按实际尺寸 ×dpr 设置，尺寸为 0 时重试最多 6 次；`draw` 用 `min(w,h)` 取半径；准备态隐藏圆环。
- 环内 meta 口径由动作组数改为全局组数（`3/34 组` 不再出现 `1/1 组`）。
- 编辑弹层支持 `theme="dark"`，专注页深色下弹层同步深色。

## 1.0.17 · 2026-11-24

**AI 找动作接真实意图分析**
- 「✦ AI 找动作」不再只按关键词过滤：本地规则先出结果保证不空屏，随后调 `libs/ai`（自定义 baseUrl/apiKey 直连，否则走云函数 `aiProxy`）分析训练意图。
- Prompt 要求先判断部位/器械/目标/限制条件，再**只从 20 个候选里**挑 6–8 个，每个必须带 ≤10 字推荐理由；温度 0.2、max_tokens 420，只收 JSON。
- 页面顶部新增意图条（`✦ AI 判断` + 意图句），每行新增绿色理由；meta 显示「AI 依据动作详情与训练部位选出 N 个」。
- 失败兜底：最多 3 次重试（4s 间隔，格式异常 1.2s）；无理由的候选直接丢弃；最终失败回落本地规则并提示原因，页面不会空。
- 结果缓存 `selfagent_aifind_v1`（按查询原句，1 小时、最多 30 条），只缓存有效结果。

**编辑动作弹层按钮统一**
- 组内控件全部统一高 56rpx、圆角 12rpx：标签 44→56、次数/重量框 60→56（74/96rpx 宽）、勾/× 52→56 固定宽 56。
- 「＋ 加一组」由裸文字改为通栏浅绿按钮（64rpx）。
- 底部取消/删除/保存统一 88rpx 高、三等分等宽、28rpx 字号。

**云函数**
- `aiProxy` 配置超时改为 45s 并重新部署（IDE 部署不覆盖云端函数超时，需在云开发控制台确认）。

包体 `1,318,431 B`，`getCodeFiles 104`。
